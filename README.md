Fully vibe coded. Fully lazy me. Still works. Cuz I audited the code.  
Spoiler: I didn't read the readme file generated by Codex. I did this to test Codex, honestly. Damn, is it powerful. But hey, technology.  
Also, it's kinda a direct update to my other Logitech battery reader. Now coded by AI! Yeah, didn't sound much better. Though I do promise the methods used are.  
Either way, here's how it works:  
  
This is a rainmeter skin that runs a helper coded in rust once it starts up.  
Don't worry, thing checks that only one instance of the helper is open, so you won't be opening up a thousand of em or something.  
Unless you want to. Manually. You weirdo. You do you.  
The helper directly reads off Logitech's HID++ or Centurion protocol to grab device name, battery values and charging status.  
No software needed. Just make sure your devices are plugged in.  
And writes em to a .tsv file saved to your ```%LOCALAPPDATA%\PeripheralBatteryWidget\```.  
The skin then reads those values directly off the .tsv file and displays it on the skin.  
And for anyone reading Codex's code and complaining that it's named "PeripheralBatteryWidget" or "headset-battery-bridge-rs", yes, I know.  
It doesn't matter, right? Codex is free to name the files whatever it wants. Code still runs. It's still optimized. It's still secure. That's what matters.
